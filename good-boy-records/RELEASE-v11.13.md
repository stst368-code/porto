# Good Boy Records v11.13

Responsive/browser calibration pass and unified panel typography.

- Establishes a shared readable type scale for module labels, controls, metadata, body copy and titles.
- Removes the tiny label/body mismatch visible in the output console.
- Calibrates large desktop, ordinary desktop, short laptop, tablet and phone layouts.
- Allows ten desktop navigation tabs to wrap within their keys instead of being ellipsised/cut off.
- Makes tablet navigation horizontally scrollable with full labels.
- Gives tablet grid rows explicit sizing instead of relying on an implicit lyrics row.
- Makes mobile carousel covers square/full-bleed to match the 1254x1254 source artwork.
- Makes mobile transport controls fill the available width cleanly.
- Prevents native image dragging from fighting the rotary pointer interaction in Chromium, Firefox and WebKit/Safari.
- QA matrix covers Chromium, Firefox and WebKit at common desktop/tablet/mobile viewports.

See `RESPONSIVE-QA-v11.13.md` for the resolution matrix, typography thresholds and browser-compatibility audit.
