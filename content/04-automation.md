# autoLabel & autoInventory
**2025 · Bibliotheca**

I built Python and SQL automation around the warehouse WMS to reduce user input, improve control and add functions that the platform did not provide natively.

## autoLabel
The system automatically printed item labels and error receipts. The safeguards contributed to inventory accuracy reaching **up to 98% over a 90-day rolling period**.

## autoInventory
A linked cycle-count system:
- generated weekly count sheets using ABC / XYZ / FSN analysis
- prioritised fast-moving and high-volume stock
- remembered historic counts
- increased frequency for discrepancy-prone items
- accepted wireless-scanner inputs
- validated counts and reported errors
- pushed finalised counts back into the WMS
- updated inventory-performance reporting
